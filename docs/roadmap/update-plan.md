# Release status and next work

The current source release is **TheMob 1.19.1** with public API/SDK 1.3.1. Admin menu, optional integrations, native BattlePass objective families, phase-aware Zombie King behavior, protected dungeons/exit altars, switchable abilities and the Minecraft 1.18–26.3 compatibility layer are implemented.

Automated evidence covers API linkage to 32 official Spigot releases, 1.18.2/26.3 simulated server lifecycles and selected real provider APIs. See [validation](../reference/VALIDATION.md) for exact scope. A live compatibility matrix, native AI/client verification and load measurements remain outstanding; they are not a promised release date or a measured performance result.

The full source and docs are prepared for later Git hosting. Publishing a Git repository or synchronizing this GitBook requires the owner's actual destination/access. The SDK's local Maven repository is not Maven Central.
