# Boss configuration

Bosses retain configured health thresholds, phase IDs, equipment, drops and integration IDs. The Zombie King coordinates heavy frontal cleaves, committed lunges, jumpable ground waves and a wounded retreat/counterattack across four phases. Telegraphs and recovery windows give players time to respond.

The phase IDs `phase1`–`phase4` remain usable in BattlePass filters. Tactics and individual abilities can be switched off globally or separately in the Skills menu. Use the [boss template](../../examples/boss_template.yml.md) for the complete YAML structure.
