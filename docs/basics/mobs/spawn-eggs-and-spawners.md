# Spawn eggs and spawners

TheMob eggs and linked block spawners resolve the same definition IDs as manual commands and the API. They obey the normal pre-spawn veto, cooldown and spawn-budget path; they are not a bypass for protection or capacity checks.

Use the Mob page in `/mob` to receive an egg or block spawner. Existing egg/spawner commands and permissions remain. Provider APIs and BattlePass receive the corresponding spawn reason, including `egg` or `spawner`.

[Complete configuration and examples](../../reference/MOBS-UND-ITEMS.md). The detailed operator references currently use German; the public API developer guide is English.
