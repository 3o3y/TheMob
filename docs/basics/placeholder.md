# Placeholders

The PlaceholderAPI bridge exports the documented `%themob_...%` placeholders when PlaceholderAPI is installed and compatible. They expose TheMob state to HUDs and other plugins; they do not grant rewards or mutate objective progress.

Configuration-specific replacement tokens and PlaceholderAPI expansion names are separate mechanisms. Use the detailed reference for supported names and null/absent-provider behavior; avoid inventing identifiers from display labels.

[Complete configuration and examples](../reference/INTEGRATIONEN.md). The detailed operator references currently use German; the public API developer guide is English.
