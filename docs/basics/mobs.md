# Mob catalogue

Every supported vanilla mob species receives TheMob levels 1–5. Minecraft 26.3 provides 90 catalog species (450 regular variants), 20 additional archetype bosses and eight original custom templates. Older Minecraft releases have smaller catalogs because later entities do not exist there.

Generated IDs use `tm_<entity-type>_lvl_<1-5>`, for example `tm_zombie_lvl_5`; `/mob mobs` gives the actual list. Natural spawning remains unchanged. Native AI is retained for species that do not use a configured custom behavior.

[Complete configuration and examples](../reference/MOBS-UND-ITEMS.md). The detailed operator references currently use German; the public API developer guide is English.
