# Twenty optional integrations

Selected RPG/server suite: Jobs Reborn, Citizens 2, PikaMug Quests, AdvancedPlugins BattlePass, PlaceholderAPI, Vault, WorldGuard, LuckPerms, EssentialsX, Multiverse-Core, MythicMobs, MMOItems, AuraSkills, mcMMO, GriefPrevention, Towny, Lands, AdvancedCrates, EconomyShopGUI/Premium and DecentHolograms.

This is a relevant selection, not a measured global popularity ranking. EssentialsX and Multiverse use standard Bukkit compatibility rather than custom service adapters. Other entries provide the specific objective, reward, protection, item, context or display functions documented below.

Run `/mob` → **Plugin-Anbindungen** or `/mob connect check`. A ready interface is not proof that every feature of every provider was live-tested together. Additional skill XP and economy rewards default to zero. Optional holograms default off. Restart after activation changes.

Developers can register other integrations through the public API. Provider item creation does not perform a shop purchase, charge money or update shop stock.

[Complete configuration and examples](../reference/INTEGRATIONEN-20.md). The detailed operator references currently use German; the public API developer guide is English.
