# Boss and item abilities

TheMob 1.19.1 removes its player skill/stats system while retaining all boss abilities, equipment bonuses and item procs. The admin menu entry is **Boss- und Itemfaehigkeiten**. Use `/mob abilities` and `abilities.yml` for switches, with `themob.abilities.manage`. Valid old boss/item switches migrate once from `skills.yml`; an existing `abilities.yml` takes precedence. Changes apply after a full server restart. See [the complete guide](../reference/FAEHIGKEITEN.md).
